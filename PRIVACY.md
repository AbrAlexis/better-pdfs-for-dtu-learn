# Privacy Policy

Last updated: September 11, 2026

Better PDFs for DTU Learn is an unofficial browser extension that improves the PDF viewer on DTU Learn.

## Data handled by the extension

The extension accesses PDF files and related page information on `learn.inside.dtu.dk` so it can display those PDFs in the bundled PDF.js viewer.

PDF files are processed locally in the user's browser. The extension does not upload PDF contents to the developer or to any external PDF service.

The browser uses the user's existing DTU Learn session when requesting a PDF. The extension does not use browser cookie APIs and does not read or store account passwords or session cookies.

## Data collection and sharing

The extension does not collect, sell, share, or transmit personal data to the developer or third parties.

The extension has:

- No analytics or telemetry
- No advertising
- No external backend
- No user tracking
- No saved search history

## Local storage

The extension may use session storage to remember whether a particular PDF should use the original Brightspace viewer. This information remains in the current browser tab and is not transmitted elsewhere.

## Network requests

The extension only requests PDF files from DTU Learn using URLs provided by the current lesson or Brightspace's content API. Selecting “Open PDF in new tab” opens the corresponding DTU Learn file directly.

## Permissions

The extension runs only on `https://learn.inside.dtu.dk/*`. This access is required to detect embedded PDFs and replace their viewer.

## Changes to this policy

This policy may be updated if the extension's functionality or data handling changes. Updates will be published with the extension source code.

## Contact

Questions about this privacy policy can be submitted through the project's GitHub issue tracker.
